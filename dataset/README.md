# Dataset

## Source

Superstore-style e-commerce sales dataset used for the E-Commerce Sales Analytics Dashboard.

## Dataset Description

The dataset contains **9,994 rows and 13 columns** covering:

- Shipping mode
- Customer segment
- Country
- City
- State
- Postal code
- Region
- Product category
- Product sub-category
- Sales
- Quantity
- Discount
- Profit
